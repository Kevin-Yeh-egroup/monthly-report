# Codex 夥伴教學檔：給沒有資訊背景的人

這份教學設計給第一次接觸 Codex、沒有資訊或程式背景的夥伴。目標不是教大家寫程式，而是讓大家學會用 Codex 協助整理工作、產出文件、檢查成果、留下紀錄。

## 教學目標

完成這份教學後，夥伴應該能做到：

1. 用自然語言說清楚要 Codex 幫忙的任務。
2. 把大任務拆成「目標、資料、格式、限制、檢查方式」。
3. 看懂 Codex 回報的進度，知道何時要補資料或修正方向。
4. 產出基本文件、報表、教案、整理表或工作清單。
5. 知道哪些事情可以交給 Codex，哪些事情需要人最後確認。

## 核心觀念

| 觀念 | 白話說法 | 教學提醒 |
| --- | --- | --- |
| 任務描述 | 先說你要完成什麼，不是先問工具怎麼用 | 「請幫我整理成主管看得懂的週報」比「幫我用 Markdown」更好 |
| 資料來源 | 告訴 Codex 可以參考哪些檔案、信件或紀錄 | 沒有資料時，Codex 只能先做模板或假設 |
| 輸出格式 | 指定要表格、段落、清單、簡報或教案 | 格式越清楚，成果越接近可直接使用 |
| 限制條件 | 說明不要做什麼、語氣要怎樣、誰會看 | 例如不要流水帳、不要太技術、要繁體中文 |
| 驗證方式 | 最後要檢查什麼才算完成 | 例如日期正確、連結可開、資料來源有註明 |

## 90 分鐘入門課

### 1. 開場：Codex 是什麼，能幫什麼忙（10 分鐘）

重點說法：

- Codex 是一個可以幫你讀資料、整理資訊、寫文件、產出初稿、檢查檔案的工作夥伴。
- 它不是主管，也不是完全自動的魔法；重要判斷仍然由人確認。
- 你不需要會寫程式，也可以用它做報表、會議準備、課程設計、資料整理。

### 2. 好任務的五個欄位（15 分鐘）

請夥伴練習用這個格式說任務：

```text
我要完成：
請參考：
請輸出成：
限制是：
完成前請檢查：
```

範例：

```text
我要完成：把這週工作整理成給主管看的週報。
請參考：我貼上的工作紀錄和會議筆記。
請輸出成：一頁式週報，包含重點摘要、完成事項、卡關、下週建議。
限制是：不要流水帳，語氣要正式但好懂。
完成前請檢查：日期是否正確、是否有列出下一步。
```

### 3. 現場示範：從零到可用文件（20 分鐘）

示範流程：

1. 先請 Codex 幫忙整理任務。
2. 補上資料來源。
3. 要求輸出一版草稿。
4. 請 Codex 自我檢查缺口。
5. 人決定要採用、修改或補資料。

示範任務可選：

- 會議紀錄整理成待辦清單。
- 每週工作整理成週報。
- 活動流程整理成工作分工表。
- 把複雜文章改寫成一般民眾看得懂的說明。

### 4. 練習：每人完成一個工作小任務（25 分鐘）

練習題：

1. 把一段雜亂工作筆記整理成三個重點。
2. 把一封長信整理成「需要回覆、需要追蹤、只是參考」。
3. 把一個活動想法整理成工作清單。
4. 把一份報告摘要改寫成給非專業人士看的版本。

檢查標準：

- 任務有講清楚。
- 輸出格式可直接使用。
- 沒有遺漏重要限制。
- 最後有請 Codex 檢查。

### 5. 常見坑與修正（15 分鐘）

| 常見坑 | 會發生什麼 | 修正方式 |
| --- | --- | --- |
| 只說「幫我整理」 | 結果可能太空泛 | 加上對象、用途、格式 |
| 沒給資料 | Codex 只能猜或做模板 | 補上原文、檔案、連結或背景 |
| 沒說不要什麼 | 可能變太長、太技術、太像流水帳 | 明確寫「不要流水帳」「不要工程術語」 |
| 沒檢查日期 | 報表容易用錯區間 | 要求列出日期區間與資料來源 |
| 完全照單全收 | 可能保留錯誤或不適合語氣 | 人要做最後判斷 |

### 6. 收尾：三個日常使用習慣（5 分鐘）

1. 先說目標，再丟資料。
2. 要 Codex 先產出可修改的第一版。
3. 最後請 Codex 檢查缺口，但由人決定定稿。

## 給夥伴的提示語模板

### 整理資料

```text
請把以下資料整理成一頁重點摘要。
讀者是沒有背景知識的夥伴。
請分成：重點結論、需要追蹤、下一步。
不要逐字重寫，請用好懂的話整理。
```

### 做報表

```text
請把以下工作紀錄整理成週報。
請包含：本週重點、完成事項、卡關、下週建議。
語氣要適合給主管或團隊看。
請避免流水帳，優先整理成主題。
```

### 做教案

```text
請把以下內容設計成 60 分鐘教學。
對象是沒有資訊背景的人。
請包含：學習目標、流程、示範、練習、常見問題。
語氣要清楚、親切、不要太技術。
```

### 請 Codex 自我檢查

```text
請檢查這份內容有沒有：
1. 日期或數字可能錯誤。
2. 太籠統、沒有下一步的地方。
3. 對沒有背景的人太難懂的詞。
4. 需要我補資料才能確認的地方。
```

## 安全邊界

- 個資、帳號、密碼、金流、醫療、法律、財務建議等內容，不能只靠 Codex 判斷。
- 對外發布前，要由負責人確認內容、數字、語氣與權限。
- 如果資料來源不完整，要在成果中標註「目前依已提供資料整理」。
- Codex 可以幫忙做初稿與檢查，但不能替人承擔專業責任。

## 教學後作業

請每位夥伴挑一個真實工作，用下面格式交出一次練習：

```text
我想完成的任務：
我提供的資料：
我要求的輸出格式：
我加上的限制：
Codex 產出的結果：
我人工修改了什麼：
下次我會怎麼問得更清楚：
```
