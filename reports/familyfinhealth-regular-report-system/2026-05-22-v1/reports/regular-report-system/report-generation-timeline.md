# 報表生成時間線

這份時間線記錄好理家在固定報表的生成節奏、已完成範圍與下一批待產項目。日期以台灣時間為準。

## 週期規則

- 每日工作簡報與營運日報：每天 08:10 產生，內容包含今日工作簡報與前一自然日營運日報。
- 週報：每週日 20:00 產生上一個週日到週六的工作週報；若週期跨月份，正式歷史索引拆成月內片段。
- 月報：每月 1 日 00:00 產生上一個自然月正式月報；當月期間保留進行中月報。
- 季報：4/1、7/1、10/1、1/1 的 00:00 產生上一季報告。
- 半年報：7/1、1/1 的 00:00 產生上一個半年度報告。
- 年度預回顧：12/28 20:00 先產生年度草稿。
- 年報：1/1 00:00 產生上一年度正式年報。
- Codex 使用演進史：每天隨日報更新 `codex-evolution-history.md`，週報/月報/季報/年報做摘要與教學化整理。
- Codex 夥伴教學檔：流程或教學素材有新發現時更新 `codex-nontechnical-partner-teaching.md`。
- Kevin 每日 Codex 使用回饋：每天隨日報更新 `kevin-codex-daily-feedback.md`，整理提問方式、任務描述、追問品質、優勢與下一步練習。
- Publish-ready 套件：每次正式更新報表後產生或更新 `publish-ready/`，只作為本機發布預備包；未經 Kevin 批准不得上傳、部署或分享。
